NotepadPP Clipboard Collector 변경 기록
========================================
v0.2.0 (2026-11-08)
- 기존 Notepad++ 모드를 유지하면서 기본 메모장, Excel, Word, 한글(HWP) 수집 대상 추가
- F8 토글 및 브라우저 클립보드 변경 감지 유지
- Excel은 선택한 빈 셀부터 같은 열 아래로 연속 입력, 기존 셀 덮어쓰기 방지
- Office/HWP COM 연결용 별도 pywin32 설치 스크립트 추가
- 대상 선택 드롭다운 및 기존 UI 개선
- 초기 Windows 실기 검증 미실시: 테스트 문서로 확인 필요

v0.1.0 (2026-11-08)
- Notepad++ 편집 버퍼 직접 추가, 브라우저 복사 감지, F8 ON/OFF
- 동일 문구 반복, 여러 줄 평탄화, 현재 탭 고정, 자동 저장 없음
