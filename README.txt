Clipboard Collector v1.2.3
=================================================
Windows 11 64비트용. ZIP 전체를 압축 해제하고 Clipboard Collector.exe를 실행하세요.
Python 설치는 필요 없습니다. EXE 옆의 _internal 폴더를 분리하거나 삭제하지 마세요.

시작하기
1. 기록할 앱과 문서/탭을 열고 기본 기록 대상을 고릅니다. 다른 앱에도 기록하려면 '함께 기록할 대상'에서 추가하세요.
2. Excel은 시작할 빈 셀을 먼저 선택합니다. 여러 창이 있다면 기록할 창을 가장 최근에 활성화하세요.
   셀을 더블클릭해 편집 중이면 Esc로 편집을 취소하거나 Enter로 확정한 뒤 시작할 빈 셀을 선택하세요. 수집 시작을 먼저 눌렀다면 Excel의 선택 상태를 최대 10초 동안 다시 확인합니다.
3. 복사 출처와 저장 방식을 선택하고 '수집 시작'을 누릅니다.
4. 화면의 대상 이름을 확인하고 필요한 텍스트를 복사합니다.
5. '수집 정지'로 마칩니다. 자동 저장을 사용하지 않았다면 대상 앱에서 직접 저장하세요.

복사 출처
- 브라우저만(기본): Chrome, Edge, Firefox, Brave, Vivaldi, Opera가 전면일 때 복사한 내용을 수집합니다.
- 모든 앱: 브라우저 외 앱의 복사도 수집합니다. 연결된 모든 기록 대상 창에서 복사한 내용은 제외합니다.
  같은 앱의 다른 창에서 복사하면 수집될 수 있습니다. 대상 창 안의 다른 탭에서 복사해도 해당 창은 제외됩니다.
- 시작할 때 선택한 앱마다 열린 문서 한 곳에 연결합니다. 수집 중 대상은 고정됩니다.
- 선택한 대상에 순서대로 기록합니다. 한 곳에서 기록 또는 저장이 실패하면 전체 수집을 멈춥니다.
  이미 기록된 내용은 유지됩니다. 화면의 대상별 기록 수와 오류 메시지를 확인하세요.
- 여러 줄과 탭은 공백으로 정리되어 한 항목이 됩니다. 같은 내용도 다시 복사하면 다시 기록됩니다.
- 50만 자 초과 텍스트는 안내 후 건너뜁니다.

이미지 수집
- Excel 또는 Word를 대상으로 선택한 뒤 '이미지 수집'을 켜세요. 기본값은 꺼짐입니다.
- '이미지 복사' 또는 화면 캡처로 클립보드에 들어온 PNG·비트맵을 수집합니다.
  화면 캡처 도구 등 브라우저 밖에서 복사하려면 '모든 앱'을 선택하세요.
- Excel은 선택한 빈 셀을 첫 기록의 기준으로 삼습니다. 그림은 셀 위에 놓이고 다음 항목은 그림 아래 첫 행부터 기록됩니다.
- Word는 문서 끝에 이미지마다 한 문단을 사용합니다.
- 원본 크기로 삽입합니다. 크기와 위치는 삽입 후 Office에서 직접 조정할 수 있습니다.
- 지원되는 이미지와 텍스트가 같은 복사에 들어 있으면 이미지 한 장을 기록합니다. 웹페이지의 혼합 서식과 이미지 파일 복사는 지원 범위에 포함되지 않습니다.
- 이미지 기록 대상은 Excel과 Word입니다. 이미지 1장당 클립보드 데이터 32 MiB, 2,400만 픽셀까지 처리합니다.
- 캡처 도구의 반복 알림으로 같은 그림이 두 번 들어가는 것을 줄이기 위해, 2초 안에 연속으로 들어온 동일한 이미지를 한 번 기록합니다.

모아 둔 텍스트 보내기
- 수집을 정지하고 Excel 또는 Word를 대상으로 선택한 뒤 '모아 둔 텍스트 보내기'를 누릅니다.
- 메모장 등에서 옮길 내용을 복사해 입력창에 붙여넣고 '보내기'를 누르세요.
- 빈 줄을 건너뛰고 한 줄씩 보냅니다. Excel은 시작 셀 아래로, Word는 문서 끝에 기록합니다.
  한 번에 1,000줄, 50만 자까지 보낼 수 있습니다. '수집을 끌 때 저장'은 보내기가 끝날 때 적용됩니다.

기록 위치와 보호
- Notepad++: 시작 당시 활성 탭 끝. 다른 탭으로 바뀌면 수집을 멈춥니다.
- Windows 메모장: 선택된 창의 편집 영역 끝. 대상 제목/탭 변경을 감지하면 멈춥니다.
- Excel: 선택한 빈 셀부터 같은 열의 다음 행에 한 항목씩 기록합니다. 기존 셀을 덮어쓰지 않습니다.
  수식으로 실행되지 않도록 문자열로 입력합니다. 셀당 최대 32,767자 등 Excel 제한을 따릅니다.
- Word: 선택된 문서 끝에 한 문단씩 추가합니다.
- 한컴오피스 한글(HWP): 이미 저장된 문서 끝에 한 문단씩 추가합니다. COM 자동화 지원이 필요합니다.
  여러 한글 인스턴스가 있으면 멈춥니다. HWP 실기 검증은 아직 하지 않았습니다.
- 앱을 새로 실행하지 않고 이미 열린 문서에 연결합니다. 대상/권한 변경, 앱 종료 등은 수집을 멈출 수 있습니다.

Word · Excel 저장 방식 (셋 중 하나)
1. 매 기록 시 저장: 항목을 추가한 뒤 문서/통합 문서 전체를 저장합니다.
2. 수집을 끌 때 저장: 화면 버튼이나 설정한 단축키로 정지할 때, 이번 수집에 추가한 항목이 있으면 저장합니다.
   프로그램 창을 정상 종료할 때도 같은 규칙을 적용합니다. 강제 종료나 전원 차단 때는 저장을 보장하지 않습니다.
3. 자동 저장 사용 안 함(기본): 대상 앱에서 사용자가 직접 저장합니다.
- 자동 저장은 이름과 위치를 정해 이미 저장한 쓰기 가능한 파일에서만 가능합니다. 저장 대화상자를 대신 처리하지 않습니다.
- 수집 내용뿐 아니라 해당 Word 문서/Excel 통합 문서의 다른 편집 내용도 함께 저장됩니다.
- Notepad++, 기본 메모장, HWP에는 자동 저장을 적용하지 않습니다.
- 저장 실패/취소를 감지하면 수집을 멈추고 '추가됐지만 저장되지 않음'과 대상 이름을 표시합니다.
  이미 넣은 항목을 다시 삽입하지 않습니다. 대상 앱에서 결과를 확인하고 직접 저장하세요.
  종료 중 저장에 실패하면 안내를 읽을 수 있도록 프로그램 창을 남깁니다.

전역 단축키와 버튼
- 화면 버튼은 항상 기본 조작 수단입니다. 단축키는 기본적으로 꺼져 있으며 F8을 자동 점유하지 않습니다.
- '단축키 변경'을 누르고 단일 키 또는 Ctrl/Alt/Shift/Win 조합을 누르면 설정됩니다. Esc는 설정 취소입니다.
- '전역 단축키 사용'을 켜면 설정한 키로 시작/정지를 전환합니다. 끄면 키를 해제합니다.
- 사용자 지정 키를 유지하며 다른 키로 자동 대체하지 않습니다. 등록 실패 팝업도 표시하지 않습니다.
  Windows 또는 다른 앱이 키를 점유하면 동작하지 않을 수 있습니다. 충돌은 사용자가 관리하며 화면 버튼을 사용할 수 있습니다.
  '설정한 단축키' 표시는 선택한 키를 뜻하며 Windows의 등록 성공을 보장하지 않습니다.

언어 및 도움말
- '언어 / Language'에서 KO/EN을 고르면 화면 문구와 도움말, 프로그램 자체 오류 안내가 즉시 바뀝니다.
- 버튼과 옵션 위에 마우스를 잠시 올리면 간단한 설명이 나타납니다.
- 대상 앱이 반환한 원문 오류, 파일명, 앱 이름은 그대로 표시될 수 있습니다.
- 언어, 대상, 출처, 저장 방식, 단축키, 이미지 수집 설정을 다음 실행에도 기억합니다.
  시험판 설정: %LOCALAPPDATA%/ClipboardCollector/phase2-preview-settings.json

주의
- Windows 11에서 개발했습니다. Linux, macOS 등 다른 환경에서 동작을 보장하지 않습니다.
- 중요한 문서 대신 테스트 문서에서 먼저 확인하고 원본을 백업하세요. 자세한 이용 조건과 면책은 LICENSE.txt를 보세요.
- 모든 앱 모드에서는 개인정보나 비밀번호 등 원치 않는 내용도 복사 시 기록될 수 있으므로 사용 후 수집을 끄세요.
- 자동 실행 등록, 원격 통신, 업로드 기능은 없습니다. 이 앱 자체에 자동 기록 보관 파일은 없지만 대상 앱에 입력한 내용과 설정은 남습니다.
- 관리자 권한 앱과 일반 권한 앱 사이의 접근 제한, 대상 앱 버전과 보안 설정에 영향을 받을 수 있습니다.
- 저장 작업이 느리면 기록이 순서대로 대기합니다. 항목 1,000개 또는 이미지 4장이 처리 중이면 추가 복사 시 수집을 멈춥니다.
  빠른 연속 복사, 클립보드 점유, 지연 렌더링 등으로 읽기가 실패하면 멈춥니다. 마지막 기록과 원문을 비교하세요.

개인 수정용 소스
source/에는 Python 소스와 실행/빌드 스크립트가 있습니다. 일반 사용자는 열 필요 없습니다.
Windows 64비트 Python 3.9 이상: https://www.python.org/downloads/windows/
소스 실행: Run.cmd. Office/HWP 및 이미지 의존성: Install_Office_HWP_Support.cmd.
빌드: Build_EXE.cmd (PyInstaller --onedir). EXE와 _internal을 함께 보관하세요.
