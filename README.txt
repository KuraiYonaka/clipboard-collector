NotepadPP Clipboard Collector v0.2.0 (Windows x64)
=================================================
기존 v0.1.0 확장판 / Python 3.9 이상 64비트 / F8 토글

기능
- 브라우저에서 Ctrl+C 또는 웹페이지 복사 버튼을 사용하면 클립보드 텍스트를 수집합니다.
- 여러 줄의 텍스트도 한 줄로 정리하여 대상 문서 끝에 추가합니다.
- 복사 이벤트마다 기록하므로 동일 텍스트도 반복 복사 가능합니다.
- 수집 OFF에는 기록하지 않습니다. 브라우저가 전면에 있을 때만 기록합니다.
- 대상 앱을 선택하고 F8 ON / 다시 F8 OFF. 파일 자동 저장은 하지 않습니다.

지원 앱과 기록 방식
1) Notepad++ : 열려 있는 현재 탭 끝에 한 줄씩 추가 (기존 방식 유지)
2) Windows 기본 메모장 : 열려 있는 편집기의 끝에 한 줄씩 추가 (Win10 구형 Edit / Win11 RichEdit 대상)
3) Microsoft Excel : 활성 시트에서 F8 시작 당시 선택한 비어 있는 셀부터 같은 열의 다음 행마다 한 항목씩 입력
4) Microsoft Word : 현재 문서 맨 끝에 한 문단씩 추가
5) 한컴오피스 한글(HWP) : 실행 중인 한글의 저장된 문서 맨 끝에 한 문단씩 추가. 한글 COM 자동화 지원 설치가 필요.

실행
1. 기존 프로그램을 종료하고 압축을 풀어 '실행.cmd'를 시작합니다.
2. 창에서 기록 대상을 선택하고 그 앱에서 수집할 문서/탭을 활성화해 둡니다.
3. F8을 누릅니다. 프로그램 창에 ON과 대상 이름이 나타납니다.
4. Chrome/Edge 등 웹브라우저에서 복사 버튼 또는 Ctrl+C를 누릅니다.
5. 대상 문서에 누적된 결과를 확인하고 F8로 끈 뒤 Ctrl+S로 저장합니다.

Excel/Word/HWP는 pywin32가 필요: 'Office_HWP_설치.cmd' 1회 실행
- 프로그램에서 대상 앱을 새로 실행하지 않고 이미 실행 중인 앱에 연결합니다.
- Excel: 빈 시작 셀을 미리 선택해야 하며 기존 데이터가 있으면 덮어쓰지 않고 즉시 중지합니다.
- Excel: '=','+' 등으로 시작하는 복사 문구는 수식이 아닌 문자열로 입력합니다.
- Word: 기존 문서를 보존하면서 마지막 문단 뒤에 텍스트를 덧붙입니다.
- 한글: 실행 중인 인스턴스가 여러 개면 오입력 방지를 위해 중지합니다.
- 한글: 저장된 문서가 있어야 하며 다른 문서로 바꾸면 수집을 중지합니다.
- 한글: 구버전이나 보안 설정에 따라 실행 중인 문서의 자동화 연결을 지원하지 않을 수 있습니다.
- 기본 메모장: 다른 탭으로 변경될 경우 제목/편집 영역을 확인해 중지합니다.

안전성 / 주의
- Windows 11에서 Notepad++와 Excel 수집을 확인했습니다. 기본 메모장은 대상 인식과 텍스트 추가를 확인했습니다.
- Word와 HWP는 실기 검증 전입니다. 먼저 테스트 문서에서 확인해 주세요.
- 기존 파일 자체를 직접 수정하지 않습니다. 편집기 버퍼만 변경되므로 저장은 사용자가 합니다.
- 관리자로 실행 중인 문서는 일반 권한 프로그램에서 접근이 차단될 수 있습니다.
- 여러 개의 같은 프로그램이 열렸을 때에는 활성 문서/가장 최근 창에 연결할 수 있으므로 ON 메시지에서 대상을 확인하세요.
- 웹페이지에서 복사한 내용에는 개인정보가 섞일 수 있으므로 수집이 끝나면 F8을 꺼 주세요.
- 프로그램 자동실행, 시작프로그램 등록, 원격 통신, 자동 업로드 기능은 없습니다.
- F8이 다른 프로그램에서 사용 중이라면 화면 버튼으로 ON/OFF 하세요.

EXE 제작
- 'EXE_빌드.cmd' : PyInstaller+pywin32 설치 후 dist\NotepadPP_ClipboardCollector.exe 생성.
- 빌드된 EXE 사용자는 Python 설치가 필요하지 않습니다.

지원 브라우저: Chrome, Edge, Firefox, Brave, Vivaldi, Opera

참고: 이 프로그램은 한글(HWP)와 Word의 자동 저장을 수행하지 않습니다.
